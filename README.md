# BAD REVIEWS

Кооперативный комедийный хоррор для 1–5 игроков. Ночная смена в отеле «Уют» с рейтингом 1,2 звезды: заселяйте странных гостей, выполняйте заявки, не шумите на лестнице и доживите до утренних отзывов.

Это браузерный прототип первой ночи. Игра работает прямо в браузере, отдельный сервер не нужен.

## Как играть вместе

1. Открой сайт игры (ссылка GitHub Pages — в настройках репозитория, раздел **Pages**).
2. Один игрок нажимает **«Создать комнату»** и получает код из четырёх букв.
3. Остальные вводят код в поле **«Код друга»** и нажимают **«Войти»**.
4. Хост нажимает **«Начать смену»**.

Голосовой чат включается галочкой в комнате ожидания: слышно тех, кто рядом, и громкость зависит от расстояния. Лучше всего игра работает в Chrome или Edge.

Если подключиться не получается, скорее всего, мешает строгая сеть (корпоративная или мобильная с жёстким NAT). В этом случае попробуйте другую сеть.

## Сохранения

- Во время смены игра автоматически сохраняет состояние примерно раз в 5 секунд.
- `Escape` открывает меню паузы. В одиночной игре время останавливается; в кооперативе общая смена продолжает идти.
- После перезагрузки страницы кнопка **«Продолжить»** восстанавливает текущую смену.
- Кооперативный игрок может вернуться в ту же комнату отдельной кнопкой. Если перезагрузился хост, он заново открывает комнату с прежним кодом, остальные подключаются обратно, после чего хост продолжает сохранённую смену.
- После прохождения первой ночи сохраняются итог, рейтинг и деньги. Ночь 2 пока находится в разработке; сохранение уже содержит версию и список пройденных ночей для будущего продолжения.

Сохранение хранится локально в браузере. Очистка данных сайта удалит его.

## Что есть в первой ночи

- Отель на 13 этажей: открыты холл, лестница, 2-й и 3-й этажи. Лифт не работает, выше 3-го этажа — закрыто.
- 8 номеров, собранных из конструктора: планировка × тема (советский, бархатный люкс, охотничий, детский, затопленный, перевёрнутый). Каждая игра раскладывает их по-новому.
- Ресепшен: документы гостя, вопросы, архив броней и выбор ключа. Не тот номер — жалоба, а жалоба оживает.
- Заявки по телефону: полотенца, кран, радио в пустом номере, свет на этаже.
- Шумоед: приходит на звук. Бег слышно далеко, шаги — близко, присевшего — не слышно.
- «Директор страха»: случайные пугалки на лестнице, в коридорах и номерах.
- Утро: отзывы гостей и новый рейтинг.

## Для разработки

Сборки нет: это обычные файлы `index.html` и `js/*.js`.

- `js/base.js` — звук, текстуры, персонажи
- `js/world.js` — отель, лестница, этажи, номера
- `js/net.js` — комнаты по коду (PeerJS) и голосовой чат
- `js/game.js` — экраны, игрок, гости, заявки, монстр, пугалки
- `js/config.js` — публичная конфигурация адреса TURN Worker (без секретов)
- `worker/` — Cloudflare Worker, выдающий краткоживущие TURN-данные

Локальный тест двух игроков в двух вкладках одного браузера: откройте `index.html?local` через локальный сервер (например, `python3 -m http.server`).

### TURN для разных сетей

Игра умеет получать временные Cloudflare Realtime TURN credentials через Worker. До его подключения остаётся прежний STUN/P2P-режим.

1. Создайте Realtime TURN key в Cloudflare.
2. Разверните `worker/turn-credentials.js` с конфигурацией `worker/wrangler.jsonc`.
3. Добавьте Worker secrets `TURN_KEY_ID` и `TURN_KEY_API_TOKEN` — не коммитьте их.
4. Укажите публичный URL `/turn-credentials` в `js/config.js`.

Worker принимает запросы только с `https://lamurlissa-ui.github.io`, не кеширует credentials и выдаёт ключи на 24 часа.
